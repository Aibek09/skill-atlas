# Contributing to Skill Atlas

Thank you for helping improve the catalog.

## Suggesting a resource

Open an issue or pull request with:

- The resource name and canonical GitHub URL
- A concise, neutral description written in your own words
- The most appropriate existing category
- Whether it is an individual skill, collection, tool, guide, or directory
- A note confirming that the repository is publicly accessible and has a visible license or clear reuse terms

Submissions should be useful for AI-agent workflows, maintained enough to evaluate, and link directly to the original source. Do not submit copied skill contents, affiliate links, link shorteners, mirrors, or repositories that require secrets in unsafe ways.

## Catalog standards

- Use factual descriptions; avoid “best,” “verified,” “safe,” or ranking claims.
- Link only to `https://github.com/...` sources.
- Prefer the canonical repository or exact skill directory/file.
- Avoid duplicate URLs and substantially duplicate entries.
- Do not imply endorsement by Skill Atlas or the linked author.
- Keep third-party names and trademarks attributed to their owners.

## Development

1. Fork the repository and create a focused branch.
2. Edit `dist/index.html`.
3. Run `npm test`.
4. Preview the site at desktop and mobile widths.
5. Open a pull request explaining the change and its source.

By contributing original code or prose, you agree that it may be distributed under this repository's MIT License. Do not contribute material you do not have permission to share.
