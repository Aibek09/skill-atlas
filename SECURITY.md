# Security Policy

## Supported version

The current `main` branch is supported.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could put visitors or contributors at risk. Use GitHub's **Report a vulnerability** option under the repository's Security tab if private vulnerability reporting is enabled. Otherwise, contact the repository owner privately through their GitHub profile.

Include the affected page or file, reproduction steps, impact, and any suggested mitigation. Do not include credentials, private data, or exploit code that affects third parties.

## Scope

Skill Atlas is a static directory and does not execute code from linked repositories. Security reports may cover this website and its deployment workflow. Vulnerabilities in linked third-party projects should be reported to their respective maintainers.

Always review third-party source code, licenses, permissions, dependencies, and scripts before installation or execution.
